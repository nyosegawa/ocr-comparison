# アノテーションシステム 設計ドキュメント

## 概要

手書きOCR比較評価のための軽量アノテーションツール。画像上に矩形を描画し、対応するテキストを入力する。

## 技術選定

- **フロントエンド:** TypeScript, React, Tailwind CSS 4
- **バックエンド:** Node.js (Express or Hono)
- **データ保存:** JSONファイル（ローカルファイルシステム）
- **アノテーション描画:** Canvas API（自前実装）
- **接続:** WSL上で動作、MacからTailscale経由でアクセス

### ライブラリを使わない理由

Annotorious等の既存ライブラリも検討したが（[調査結果](../research/existing-tools-survey.md)参照）、要件がシンプルなためCanvas APIで自前実装する。矩形描画・選択・テキスト入力程度であれば依存を増やすメリットが薄い。

## データモデル

### アノテーションJSON (`annotations/{imageId}.json`)

```json
{
  "imageId": "img_001",
  "imagePath": "uploads/img_001.png",
  "width": 1920,
  "height": 1080,
  "annotations": [
    {
      "id": "a1b2c3",
      "rect": { "x": 100, "y": 200, "w": 300, "h": 50 },
      "text": "手書きテキスト",
      "createdAt": "2026-03-16T12:00:00Z",
      "updatedAt": "2026-03-16T12:00:00Z"
    }
  ]
}
```

- `rect` の座標は画像のピクセル座標（表示サイズではなく元画像基準）
- `id` は nanoid 等で生成

## ユーザー操作フロー

1. 画像をアップロード（またはリストから選択）
2. Canvas上でドラッグして矩形を描画
3. テキスト入力欄が表示される → テキストを入力してEnter
4. アノテーション一覧に追加される
5. 既存の矩形をクリックで選択 → テキスト編集 or 削除
6. 保存ボタンまたは自動保存でJSONに永続化

## Canvas実装方針

- 2層構成: 背景レイヤー（画像）+ 前景レイヤー（矩形描画）
- マウスイベント: `mousedown` → `mousemove` → `mouseup` で矩形描画
- 表示座標 ↔ 画像座標の変換（ズーム・リサイズ対応）
- 選択中の矩形はハイライト表示
- 矩形内にテキストのプレビュー表示（省略形）

## API設計

| Method | Path | 説明 |
|--------|------|------|
| GET | `/api/images` | 画像一覧取得 |
| POST | `/api/images` | 画像アップロード |
| GET | `/api/images/:id` | 画像ファイル取得 |
| GET | `/api/annotations/:imageId` | アノテーション取得 |
| PUT | `/api/annotations/:imageId` | アノテーション保存（全体上書き） |
