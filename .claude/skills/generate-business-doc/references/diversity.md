# 多様性ガイドライン

## 多様性軸

データ生成時に以下の軸でバリエーションを確保する。

### 業種

IT / 製造 / 飲食 / 建設 / 小売 / 医療 / 不動産 / 教育

均等に分散させる。manifest.json の coverage.industry を確認し、少ないものを優先。

### 地域

北海道 / 東北 / 関東 / 中部 / 近畿 / 中国 / 四国 / 九州

東京偏重を避ける。各地域の実際の住所形式を使う。

住所例:
- 北海道札幌市中央区北1条西2丁目
- 宮城県仙台市青葉区一番町3-1-1
- 東京都渋谷区神宮前1-2-3
- 愛知県名古屋市中区栄3-4-5
- 大阪府大阪市北区梅田1-2-3
- 広島県広島市中区紙屋町1-1-1
- 香川県高松市番町1-8-15
- 福岡県福岡市博多区博多駅前2-1-1

### 規模

- **小規模**: 明細1-2行、合計1万円未満
- **中規模**: 明細3-5行、合計1万-50万円
- **大規模**: 明細6-20行、合計50万円以上

### レイアウトスタイル（請求書・名刺）

LLM がレイアウトを生成するため、以下の軸でバリエーションを出す:

#### 配色
- `monochrome` — 黒・グレー基調
- `blue` — ネイビー/ブルー系アクセント
- `gray` — ライトグレー背景、ダークグレー文字
- `green` — グリーン/ティール系アクセント
- `warm` — ブラウン/ベージュ系

#### 罫線スタイル
- `solid` — 実線
- `dashed` — 破線
- `none` — 罫線なし（余白で区切り）
- `double` — 二重線
- `thin` — 細い薄いグレー線

#### ヘッダー配置
- `left` — 左寄せ
- `center` — 中央揃え
- `right` — 右寄せ
- `split` — 左右分割（請求先/請求元）

#### テーブルスタイル
- `bordered` — 全セルにボーダー
- `striped` — 交互背景色
- `minimal` — ヘッダーのみボーダー
- `compact` — 余白少なめ

#### 日付表示形式
- `2026年3月17日`
- `2026/03/17`
- `令和8年3月17日`
- `R8.3.17`

### レイアウトスタイル（レシート専用）

レシートは **POS サーマルプリンタ印字** の外観を再現する。
Web デザイン風のカラフルなスタイルは **一切使わない**。

#### 配色（固定）
- 常に `monochrome` — 黒テキスト + 白背景のみ

#### 用紙幅
- `58mm` — コンビニ・小規模店舗（viewport 220px）
- `80mm` — スーパー・中大規模店舗（viewport 300px）

#### 区切り線の文字
- `━` — 太い全角ダッシュ
- `─` — 細い全角ダッシュ
- `＝` — 全角イコール
- `*` — アスタリスク
- `-` — 半角ハイフン

#### 明細表示パターン
- `one_line` — 品名と金額を1行に
- `two_line` — 品名の下に数量×単価
- `inline_qty` — 品名横に数量

#### 合計強調方法
- `large_font` — フォントサイズを大きく
- `inverted` — 黒背景＋白文字（反転）
- `double_line` — 二重区切り線で囲む
- `bold_spaced` — 太字 + letter-spacing

#### 日時表示形式
- `2026/03/17 12:34`
- `2026年03月17日 12時34分`
- `R8.03.17 12:34`

#### metadata 例（レシート）
```json
{
  "layout_style": "pos_thermal",
  "paper_width": "80mm",
  "separator_char": "━",
  "item_display": "two_line",
  "total_emphasis": "inverted",
  "date_format": "2026/03/17 12:34"
}
```

### 文字特性

- 漢字密度が高い品目名（例: 基礎構造物補強工事）
- カタカナ外来語混在（例: クラウドサーバーホスティング）
- 英数字混在（例: AWS EC2 インスタンス利用料）
